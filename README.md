**TaskFlow** is a full-stack task manager for organizing your work and personal to-dos.
Group tasks into color-coded projects, set due dates and priorities, and see at a glance
what's overdue, what's due today, and how much you've completed.

### Highlights
- **React + Vite** frontend with a responsive layout and automatic dark mode
- **Express REST API** with input validation and clear error messages
- **SQLite** database using Node's built-in `node:sqlite`, so there's nothing native to compile
- Projects with open-task counts; deleting a project removes its tasks
- Filter by Active / Done / All and search titles and notes
- Dashboard showing open, due today, overdue, and % complete
- API tests written with Node's built-in test runner

### Tech stack
| Layer | Tools |
| --- | --- |
| Frontend | React 18, Vite, CSS |
| Backend | Node.js, Express |
| Database | SQLite (`node:sqlite`) |
| Testing | `node:test` |
